# Module 60 — Health & Sustainable Pace

Writes `me/health.md` and, if a work rhythm is set,
`constitution/The-Rhythm.md`. **Opt-in by design** — ask before assuming
the user wants any proactive wellbeing behavior at all.

## Topics to cover

- **Ask first, plainly:** "Do you want Claude to ever proactively flag
  overwork or an unsustainable pace, or would you rather it just focus on
  the work?" Both are complete, valid answers. If the answer is no, write
  `me/health.md` as a short note saying so and stop — don't ask the
  remaining questions in this module.
- If yes:
  - **Typical work hours/rhythm** — when do they actually work, and is
    there a pattern worth naming?
  - **Deep-work ratio** — offer one commonly-used example (e.g. a block of
    focused time followed by a shorter open window) but ask for *their*
    real ratio, not the example.
  - **Framing preference** — how should a flag actually sound? Ask them to
    describe it, don't assume "gentle" is universally right — some people
    want blunter, some want closer to silent-unless-severe.
  - **What NOT to do** — explicit boundaries: no diagnosis, no medical
    advice, no repeated nagging, no guilt language, or whatever specific
    lines matter to them.
  - **Fitness/nutrition** — optional, only go here if they want to.

## Interview notes

This module has real potential to feel invasive if rushed. Keep the tone
matter-of-fact, make the opt-out genuinely easy to take, and don't probe
past a "no" on the first question.

## What gets written

`me/health.md` fully, or the short opt-out note. `constitution/The-Rhythm.md`
only if a real work rhythm was stated — leave the placeholder tokens in
place otherwise rather than inventing a default.
