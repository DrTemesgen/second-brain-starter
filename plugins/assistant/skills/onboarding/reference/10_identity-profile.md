# Module 10 — Identity & Profile

Writes `me/profile.md`. The reference file for "who is this person" that
every other agent/skill pulls from instead of re-asking.

## Topics to cover

- Full name, and whether there's a professional/formal form that differs
  from what they answered in Module 00.
- Credentials, titles, degrees, licenses worth surfacing — ask what they'd
  actually want in a one-line bio, not an exhaustive CV dump.
- Location, languages — including whether English (or whatever the primary
  working language is) is a second language, so Claude reads for intent on
  typos rather than flagging them (a real, common, non-trivial preference —
  ask directly rather than assuming either way).
- Contact channels worth Claude knowing about (not for outreach — for
  reference, e.g. filling in a bio or a form draft).
- Current roles — what they actually do right now, with enough detail that
  Module 50 (Work & Project Domains) has something to build on.
- Earlier career — brief, chronological, only as much as feels useful.
- Certifications, memberships, publications — skip sections that don't
  apply rather than leaving awkward "N/A" placeholders.
- "How they work" — session habits, tools already in daily use. This is a
  good moment to ask "what's already working for you that this system
  shouldn't get in the way of?"

## Interview notes

This module tends to run fast and factual — it's closer to a structured
intake than a values-laddering conversation. Still apply "one question at a
time," but don't force deep probing on a straightforward fact like a job
title. Save the laddering discipline for modules where it earns its keep
(20, 40, 50).

## What gets written

Fill every section of `me/profile.md`'s existing structure — replace each
`<!-- -->` comment with the real content, keep the section headers as-is.
