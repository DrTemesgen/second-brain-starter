# Module 40 — Values & Principles

Writes `me/values.md`, and optionally `constitution/Ethos.md`. The
laddering- and 5-Whys-heaviest module in the whole interview — this is
where thin answers matter most to catch.

## Topics to cover

- **Foundations** — a small set of value pillars that should hold steady
  across different kinds of decisions. Ladder hard here: a first answer
  like "honesty" or "impact" is a starting point, not a finished one — push
  for what that actually means in a decision they've really faced.
- **A named framework, optional** — ask if they have (or want to co-build)
  a more structured personal philosophy for evaluating big decisions.
  Offer the *idea* of a structured decision filter as one example pattern
  — a named root principle with sub-components applied consistently —
  without supplying any actual content; if they don't want one,
  foundations + guardrails alone are a complete, valid values.md.
- **AI-content guardrails** — concretely: claims Claude should never make
  on their behalf, tones to avoid, topics needing extra care.
- **Decision-evaluation lens** — operationally, when should Claude
  actually consult this file? "Before recommending a direction on
  anything with real stakes" is a reasonable default to offer.
- **The Ethos exercise (optional, flag it as optional before starting)** —
  point them at `constitution/Ethos.md`'s own prompting questions if they
  want to write a "why" beneath the rules. This is genuinely skippable;
  say so plainly, don't make skipping feel like settling for less.

## Interview notes

Use 5-Whys on any positioning-shaped claim ("I value doing good work") —
push toward the root reason, not the polished surface version. If two
consecutive probes produce nothing new, that's the saturation signal —
close the module rather than manufacturing a third probe.

## What gets written

Fill `me/values.md`. Only touch `constitution/Ethos.md` if they actually
did the optional exercise — otherwise leave it exactly as shipped, blank.
